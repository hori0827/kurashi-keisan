この計算は概算です。 下地の吸い込み具合、素材、道具（ハケ・ローラー・スプレー）、気温、塗り手の慣れによって 実際に使う量は変わります。メーカーが塗り面積を「4.9〜7㎡」のように幅で示しているのは このためです。仕上がりや適合する下地については、製品の説明書と販売店・施工店などの 専門家にご確認ください。計算結果にもとづく購入について責任を負いかねます。

計算のしかた

1. 塗る面積を出す（窓とドアは差し引く）

壁の幅×高さを足し合わせ、そこから窓やドアなど塗らない部分の面積を引きます。 塗料は液体なので、塗らない面積の分はそのまま要りません。

同じ部屋でも壁紙の必要量では逆に 開口部を差し引きません。壁紙は窓の上下に出る切れ端が他の面に回せず、 引くと材料が足りなくなるためです。同じ「必要量計算」でも材料によって作法が違います。

2. 「1Lで何㎡塗れるか」は製品ごとに違う

ネット上の計算ツールの多くは「水性なら8㎡/L」のような単一の値を使っていますが、 メーカーが実際に公表しているのは幅のある範囲です。 たとえばカンペハピオ「室内かべ用塗料」は0.7Lで 4.9〜7㎡（1回塗り）。1Lあたり7〜10㎡で、上下に4割以上の開きがあります。

このツールは範囲のまま計算し、答えも範囲で出します。 そのうえで最も塗料を食う側に予備を足した量を購入の目安にしています。 余った塗料は次の補修に使えますが、途中で足りなくなると乾き際が変わり仕上がりに差が出ます。

3. いちばんの落とし穴は「何回塗り基準の面積か」

缶に書かれた塗り面積が1回塗り基準か2回塗り基準かは製品によって違います。 たとえばアサヒペン「水性多用途EX」の 40〜50㎡（7L）は2回塗りの数字で、 同社「水性多用途カラー」の 36〜47㎡（5L）は1回塗りの数字です。 これを取り違えると必要量が倍または半分にずれます。 このツールでは製品ごとに基準回数を持たせ、基準と違う回数を選んだときは画面に断りを出します。

4. 缶は「組み合わせ」で買う

塗料は0.7L・1.6L・3L・7Lのような決まった容量でしか売られていません。 5.3L必要でも5.3Lの缶は無いので、合計が必要量を超える組み合わせを選ぶことになります。 本数を減らすほど余りが増え、余りを減らすほど本数が増えます。 どちらが安いかは実売価格しだい（一般に大容量ほど1Lあたりは安くなります）なので、 このツールは本数と余りの候補を並べて示し、選択は使う人に委ねます。

よくある質問

6畳の部屋の壁を塗るには何リットル必要ですか

一般的な6畳間（約360cm×270cm・天井高250cm）の壁4面は31.5㎡。 腰高窓1つとドア1つを差し引くと約27㎡です。 カンペハピオ「室内かべ用塗料」で2回塗りするなら理論値は約5.4〜7.7L、 予備10%を含めて約8.5L。7L缶＋1.6L缶の2缶が目安になります。 上のボタンから同じ条件を入力できます。

壁紙（クロス）の上から塗れますか

製品によります。カンペハピオ「室内かべ用塗料」は塗れるものとして 「ビニールかべ紙」を挙げています。一方で、はがれかけている壁紙や、 凹凸の大きいもの、汚れが浮くものは適さないとされることがあります。 使う製品の表示を必ず確認してください。

1回塗りで済ませてもいいですか

下地の色を大きく変える場合（濃い色から白へ、など）は、1回では下の色が透けます。 2回塗りが基本と考え、塗り回数の選択を「2回塗り」のままにしておくのが無難です。 なお2回目は塗り重ね時間を空ける必要があり、 たとえばアサヒペン「水性多用途EX」では夏期2時間以上・冬期6時間以上とされています。

缶に書かれた数字を直接入れたい

製品の選択で「缶の表示を直接入力する」を選ぶと、 手元の缶の標準塗り面積・容量・基準回数を入力して計算できます。 収録していない製品や、業務用の塗料はこちらを使ってください。
