この計算は概算です。 部屋の形状、柄の向き、下地の状態、施工方法によって必要量は変わります。 実際の発注数量は、購入先の販売単位や施工店・専門家にご確認ください。 計算結果にもとづく発注について責任を負いかねます。

計算のしかた

1. 壁1面ごとに「巾数」を数える

壁紙はロール状で、幅が決まっています。国産の量産品は実寸で92cm前後ですが、 メーカーや専門店の採寸ガイドでは余裕をみて90cmで計算するのが通例です。 壁の横幅を壁紙の幅で割り、端数は必ず切り上げます。 切り捨てると材料が足りなくなります。

  • 横幅360cm ÷ 90cm ＝ 4.0 → 4巾
  • 横幅270cm ÷ 90cm ＝ 3.0 → 3巾
  • 横幅181cm ÷ 90cm ＝ 2.01 → 切り上げて 3巾

2. 1巾あたりの長さに切りしろを足す

貼るときに上下を裁ち落とすため、壁の高さに10cmほど足します。 天井高250cmなら1巾あたり260cmです。

3. 柄物は「縦リピート」で決まる

柄の入った壁紙は、隣り合う巾で柄を合わせる必要があります。 このとき必要な長さは切りしろではなく柄の繰り返し単位（縦リピート）で決まります。 天井高をリピートで割って切り上げ、さらに柄合わせの余裕として1リピート分を足します。

  • 天井240cm・縦リピート64cm → 240÷64＝3.75 → 切り上げて4 → 余裕1つ分を足して5 → 5×64＝320cm

4. 窓やドアは差し引かない

意外に思われますが、開口部の面積は引きません。 窓の上下にできる部分は幅の狭い切れ端になり、他の面へ回せないことが多いためです。 差し引いて発注すると材料が足りなくなります。 大きな掃き出し窓など、明らかに1巾まるごと不要な箇所がある場合だけ、 その壁面の幅を分けて入力してください。

なおペンキ・塗料の必要量では逆に、 開口部を差し引きます。塗料は液体なので、塗らない面積の分は そのまま要らないためです。同じ部屋でも材料によって作法が反対になります。

よくある質問

6畳の部屋だと何メートル必要ですか

一般的な6畳間（約360cm×270cm）の壁4面を天井高250cmで計算すると、 14巾・36.4mになります。予備10%を含めると約40mが目安です。 上のボタンから同じ条件を入力できます。

天井も貼る場合は

天井は「幅＝部屋の短辺」「高さ＝部屋の長辺」として1つの面に見立てて入力してください。 ただし天井は継ぎ目が目立ちやすく、切りしろも多めに要ります。

生のり付きと生のりなしで計算は変わりますか

必要な長さの計算は同じです。生のり付きは1m単位の切り売りが多く、 生のりなしはロール単位（品番により長さが異なる）で売られることが多いので、 販売単位に合わせて切り上げてください。
